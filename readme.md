# XOXO.FASHION.GIRL

- **Nome do projeto:** XOXO.FASHION.GIRL
- **Nome do aluno:** Amira Jamal Bazerbachi
- **Tema escolhido:** Blog de moda
- **Tecnologias utilizadas:** HTML5, CSS3, JavaScript, Bootstrap 5 e Gemini IA

## Descrição do projeto

Este projeto consiste em um blog de moda e tecnologia que apresenta as últimas notícias, tendências e dicas de beleza do mundo da moda. O site também reúne imagens dos principais desfiles das semanas de moda ao redor do mundo, permitindo ao público acompanhar diferentes estilos e referências do universo fashion.

Além disso, o projeto conta com um **Closet Virtual**, no qual são disponibilizadas imagens de roupas e sapatos para que os usuários possam explorar e criar diferentes combinações de looks.

Por fim, o site possui uma página dedicada ao **Bootstrap**, apresentando explicações sobre o framework, seu funcionamento, sistema de grid, responsividade e principais componentes utilizados no desenvolvimento web.

## Breve explicação sobre o desenvolvimento

Para o desenvolvimento do site, inicialmente utilizei o **Canva** para criar um protótipo da interface, definindo a tipografia, a paleta de cores, a organização das páginas e os principais elementos que fariam parte do projeto.

Após a criação do protótipo, utilizei o **Gemini** como ferramenta de apoio no desenvolvimento, enviando as referências visuais criadas no Canva para auxiliar na implementação da interface. A partir dessas referências, foram desenvolvidos os primeiros códigos e elementos visuais do site, incluindo um design moderno com efeitos de vidro (*glassmorphism*).

Posteriormente, realizei diversas modificações diretamente no código para ajustar a interface, corrigir elementos e aproximar o resultado final do projeto desenvolvido no protótipo. Dessa forma, o desenvolvimento envolveu tanto o uso de ferramentas de inteligência artificial como alterações e ajustes manuais realizados durante a construção do site.

As notícias e tendências apresentadas no blog foram pesquisadas em **sites oficiais e fontes relacionadas ao mundo da moda**. Já os textos da página dedicada ao Bootstrap foram desenvolvidos com auxílio do Gemini, seguindo os requisitos definidos para o projeto.

Durante a implementação, também foram utilizados componentes do **Bootstrap 5**, como **Cards, Carousels e Navbar**, presentes em diferentes áreas do site, incluindo a seção de tendências da página inicial e o **Closet Virtual**.
